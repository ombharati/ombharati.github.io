Budget Guardian

Financial decision-support CLI evaluating purchases against monthly savings goals.

Python CLI Input Validation Decision Logic
GitHub Repository

Overview

Budget Guardian is a Python command-line utility built to assist users in making objective purchasing decisions. Standard financial tools typically perform basic subtraction, answering only whether money remains in an account today. They fail to highlight whether an expenditure compromises predefined monthly savings targets.

The software evaluates purchases contextually prior to execution, distinguishing between what is technically affordable and what threatens long-term savings goals.

Key Features

  • Post-purchase liquidity evaluation calculating exact remaining discretionary capital after planned expenses.
  • Savings target protection distinguishing between affordable purchases and transactions that breach monthly reserve targets.
  • Context-aware essential expense handling providing nuanced guidance when critical necessities require dipping into savings reserves.
  • Strict input validation detecting negative figures, non-numeric strings, impossible savings targets, and pre-existing deficit balances before processing.

How It Works & Architecture

The program is structured as a single-pass decision engine. The execution begins by collecting parameters: total monthly budget, current expenditures to date, savings target, planned purchase price, and whether the purchase is categorized as an essential living expense.

Each input is processed through validation checks to confirm mathematical plausibility. The computational engine then calculates immediate liquidity:

available_funds = total_budget - current_expenditures
post_purchase_balance = available_funds - purchase_price

Based on the relationship between post-purchase balance and target savings, the application outputs one of three clear decisions: SAFE TO BUY (savings intact), WARNING (affordable but savings compromised), or CRITICAL DEFICIT (purchase exceeds total liquidity).

My Role & What I Learned

I developed this tool independently to practice writing defensive, well-structured Python code. The project emphasized the importance of rigorous input sanitization, handling edge cases gracefully, and translating real-world decision tradeoffs into transparent software rules.
