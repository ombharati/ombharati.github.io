Overview

CYBERGUARD is a collaborative hackathon project built to provide local-first, privacy-preserving threat intelligence. Security analysts frequently need to evaluate sensitive URLs, authentication logs, and potential phishing emails without leaking company telemetry or confidential payloads to cloud LLMs or third-party APIs.

The platform decouples deterministic heuristic signal extractors from neural inference pipelines and scoring logic, allowing full assessment capabilities directly on developer-grade hardware.

Key Features

  • High-throughput local URL screener matching incoming links against an indexed dataset of 2M+ known malicious records.
  • Multi-model inference pipeline integrating Laya (ModernBERT-large on CPU, approx 80ms) for structured signal classification and quantized Qwen 8B (via Ollama on GPU) for narrative explanations.
  • Deterministic Python Risk Engine that synthesizes raw evidence into a repeatable 0 to 100 risk score and tier without handing final decision authority to neural models.
  • Cloudflare Tunnel networking setup providing secure, encrypted remote access while the stack ran locally on a development laptop (16 GB RAM, 6 GB VRAM).
  • Resilient failure boundaries ensuring that if neural backends become unavailable, scans gracefully fall back to deterministic heuristics.

How It Works & Architecture

CYBERGUARD enforces a core principle: detection tools produce evidence, but the deterministic Risk Engine makes the final decision.

When an analyst submits an indicator, the system initiates deterministic rules checking Shannon entropy, character homoglyphs, SSRF patterns, and cross-references a 2M+ URL local dataset. In parallel, the neural adapters analyze linguistic indicators and contextual intent.

All gathered signals are forwarded to the mathematical Risk Engine, which computes calibrated threat scores. An asynchronous worker then generates plain-English analyst summaries without delaying immediate scan outcomes.
