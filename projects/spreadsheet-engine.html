Spreadsheet Engine

Lightweight computation engine, AST formula parser, and dependency graph in Python.

Python 3 AST Parser Graph Algorithms DFS CLI
GitHub Repository

Overview

Spreadsheet Engine is a standalone computational core built in Python without third-party libraries. It models the core mechanics behind modern spreadsheets: coordinate-based storage, mathematical expression parsing, dynamic cell dependency tracking, and automatic downstream recalculation.

The project was built from first principles to explore Abstract Syntax Tree (AST) manipulation, directed acyclic graphs (DAGs), cycle detection in directed graphs, and structured data persistence via JSON and CSV.

Key Features

  • In-memory cell storage dictionary with clean formatted ASCII grid output for terminal interaction.
  • Safe mathematical formula parsing using Python's built-in ast module, supporting arithmetic operators, exponentiation, and parentheses without hazardous eval() calls.
  • Built-in functions and cell range aggregation, including SUM, AVERAGE, MIN, MAX, and conditional IF expressions over ranges like A1:A5.
  • Automatic dependency tracking and cascade recalculation that traverses downstream dependents when source values change.
  • Depth-First Search (DFS) circular dependency detection, safely marking cycle participants with #CIRCULAR! without terminating the process.
  • Data persistence with JSON state save/load capabilities and CSV formatted export.

How It Works & Architecture

The engine operates through four decoupled subsystems:

1. Coordinate Store: An in-memory mapping between alphanumeric cell coordinates (e.g. B2) and cell objects storing raw user inputs, computed results, precedent references, and dependent listeners.

2. AST Evaluator: When a user sets a cell formula prefixed with '=', the expression is parsed into a Python AST. The evaluator traverses binary operator nodes (Add, Sub, Mult, Div, Pow) and recursively resolves cell coordinates against the grid store.

3. Dependency Graph & Cycle Detection: Whenever formulas reference other cells, directed edges are established. Before committing a calculation, a Depth-First Search algorithm checks for cycles in the dependency tree. If a circular reference is found (e.g. A1 depends on B1 which depends on A1), the engine assigns a #CIRCULAR! error status to avoid infinite recursion.

4. Cascade Recalculation: When a precedent cell is modified or cleared, the engine notifies all listening cells, causing an orderly recalculation cascade.
