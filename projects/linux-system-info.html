Linux System Info

Lightweight host metrics inspector and Linux /proc filesystem parser.

Python 3 Linux /proc Parsing CLI SysAdmin
GitHub Repository

Overview

Linux System Info is a focused Python command-line utility that extracts and displays essential metrics from a host Linux machine. Rather than relying on heavyweight monitoring agents or external packages, it leverages the operating system's virtual filesystem and built-in Python modules.

The project was built to understand how software inspects runtime environment states directly through operating system interfaces like the /proc pseudo-filesystem.

Key Features

  • Operating system and environment inspection querying Linux distribution name, kernel release, and hardware architecture.
  • CPU core count retrieval identifying available physical and logical processing units on the host.
  • Direct memory parsing from /proc/meminfo to report exact total RAM, available memory, and compute consumption percentages.
  • Filesystem disk metrics calculation using shutil to report total, used, and free gigabytes across primary mount points.
  • System uptime calculation translating raw seconds from /proc/uptime into clean, readable hours and minutes format.

How It Works & Architecture

In Linux, the /proc directory does not contain physical files on disk; rather, it provides a window into data structures maintained in real time by the Linux kernel.

The utility implements modular reader functions:

1. Memory Extraction: The parser opens /proc/meminfo in read-only mode, extracts the MemTotal and MemAvailable keys, converts kilobyte counts into gigabytes, and derives the active memory footprint percentage.

2. Uptime Extraction: The script reads the first numeric float from /proc/uptime, representing elapsed seconds since the kernel booted, and converts the duration into human-readable hours and minutes.

3. Disk and CPU Introspection: Standard library helpers interface directly with underlying POSIX system calls to retrieve partition block sizes and core counts without spawning sub-shells.
